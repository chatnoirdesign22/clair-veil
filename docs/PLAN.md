## 1. 未決事項（SPEC 14）へのおすすめ案

### 1-1. 使用技術 → **HTML・CSS・JavaScript だけ（ライブラリなし）** をおすすめ

| 候補 | よい点 | 気になる点 |
|---|---|---|
| **A. 素の HTML/CSS/JS**（おすすめ） | ビルド（変換作業）不要。GitHub Pages にそのまま置ける。ファイルを開けば中身が読める | 共通部分（メニューなど）を7ページにコピーする必要がある |
| B. Astro など静的サイト生成ツール | 共通部分を1か所にまとめられる | ビルドが必要。初心者には仕組みが見えにくい |
| C. React など | 動きの多い画面に強い | ビルド必須・オーバースペック（大げさすぎ） |

**理由:** 仕様の「ビルド不要」に一番素直に合い、あとで自分で直すときも分かりやすいため。
共通部分の重複は、ヘッダー・フッターを JavaScript（`common.js`）で差し込む方法で減らします。

### 1-2. 写真の取得方法 → **作業環境から Unsplash の写真を直接ダウンロード** をおすすめ

- 確認済み: この作業環境から Unsplash・Pexels の画像サーバーに接続できました（どちらも応答 200＝成功）。
- Unsplash を主に使い、足りないものだけ Pexels で補います。どちらも無料・商用利用可・クレジット表記不要のライセンス（利用条件）です。
- **色味をそろえる工夫:** 白・ベージュ系の明るい写真を選び、さらに CSS（見た目を決める言語）で全写真に同じ「ほんのり明るく・彩度控えめ」の補正をかけます。
- 写真は `images/` フォルダに保存し（外部の画像を直接表示しない）、出典URLを `docs/CREDITS.md` に記録します。
- ファイルサイズを抑えるため、幅1600px以下・JPEG で保存します。

### 1-3. GitHub アカウントと公開手順 → **GitHub Pages（無料）**

- アカウントをお持ちか、あとで確認させてください（ない場合は作成手順から案内します。作成とログインはご自身で操作していただきます）。
- 流れ: リポジトリ（ファイルを置く場所）を作る → ファイルをアップロード（push＝送信）→ 設定画面で Pages を ON → URL が発行される。
- **注意:** 無料プランの GitHub Pages は、リポジトリを「公開（Public）」にする必要があります。サイトの中身は誰でも見られる状態になりますが、noindex と robots.txt で検索には出ないようにします。（「URLを知っている人だけ」は“検索で見つからない”という意味で実現します）
- commit・push はご指示があったときだけ行います。

### 1-5. セット割引 → **シンプルな2種類** をおすすめ

| 割引名 | 条件 | 割引額 |
|---|---|---|
| カット＋カラー割 | カット と カラー（またはケアブリーチ）を同時に選ぶ | −1,100円 |

### 1-6. オープニング演出 → **入れる（約1.2秒・初回のみ）** をおすすめ

- 白い画面にロゴ「clair veil」がふわっと現れて消えるだけの控えめなもの。

## 4. テスト方法

| 確認すること | 方法 |
|---|---|
| 表示・リンク切れ | アプリ内ブラウザで全ページを開き、全リンクをクリック |
| 料金計算 | 長さ×メニューの組み合わせを数パターン計算し、手計算と照合（セット割含む） |
| チャット | 5つの悩みすべてを最後まで進め、シミュレーターにメニューが入るか確認 |
| ギャラリー | 絞り込みの全組み合わせ、拡大表示と閉じる操作 |
| 予約フォーム | シミュレーターからの引き継ぎ、送信ボタンで「送信されません」表示、通信が発生しないこと（ネットワーク記録で確認） |
| レスポンシブ | 幅375〜400px と 1280px で全ページ確認、横スクロールが出ないこと |
| noindex | 全ページの `<meta name="robots" content="noindex">` を検索で確認、robots.txt の中身確認 |
| 動きを減らす設定 | 設定ON時にアニメーションが止まることを確認 |
